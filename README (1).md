# Deployments

This directory holds machine-readable deployment manifests, one per network:

- `celo-testnet.json` — Alfajores testnet (first deployment target)
- `celo-mainnet.json` — Celo Mainnet (separate, explicit, human-approved operation only)
- `dapp-config.json` — combined export consumed by the celoht-dapp frontend

**Status as of this delivery: EMPTY.**

No contracts have been deployed by Claude in this session. This sandbox has no network
access, so no real transaction was broadcast, no real address was assigned, and no real
block explorer verification was performed. Any manifest file appearing here was
generated by actually running `scripts/deployAll.ts` against a live network with a
funded deployer key — never fabricated.

To produce a real manifest:

```bash
cp .env.example .env   # fill in DEPLOYER_PRIVATE_KEY, RPC URLs
                        # (GENERAL_TREASURY, EDUCATION_TREASURY, REFORESTATION_TREASURY,
                        # GOVERNANCE_TREASURY, and USDM_ADDRESS_CELO are pre-filled with
                        # verified/confirmed values — see ARCHITECTURE.md)
npm install
npx hardhat run deployAll.ts --network alfajores
npx hardhat run configureContracts.ts --network alfajores
npx hardhat run verifyContracts.ts --network alfajores
npx hardhat run exportDeployment.ts
```
