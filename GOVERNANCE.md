# Governance

CeloHT governance is advisory voting over USDm-funded proposals. It is not a
governance-token system and does not execute arbitrary calls or control treasury
contracts. Proposal creation and administrative configuration are role-gated;
each wallet receives at most one vote per proposal.

The current Celo Sepolia deployment is the only recorded deployment. Governance
roles and treasury custody must be reviewed and transferred to an approved
multisig before any future production deployment. No Mainnet deployment is
configured or authorized by this repository.
